# Bathymetry research index: where open sea-floor and lake-bed data beat the global grid
Index of the eight regional bathymetry reports (board items i1315-i1322, run 2026-11-13). Research only. The table in section 3 was drafted by a script from the reports' own summary tables (cells copied; only the product, measured/interpolated, datum and jurisdiction-section cells are shortened, marked "[cut; see report]"; spacing and licence cells are whole) and then checked by hand against the source rows (section 3 note). The report and row named in the last two columns hold the evidence, URLs and caveats. "Beats the global grid" here means: open for use under a licence read in the report, with a spacing of 250 m or finer (GEBCO_2026 is 15 arc-second, about 460 m), not a pointer and not a "nothing open found" row.

## 2. Global baselines, in one line each
Open baseline everywhere: GEBCO_2026 (15 arc-second, public domain / OGL v3), with a per-cell Type Identifier grid (TID 10-17 measured, 40-48 predicted) in the same CEDA package, so the measured-vs-predicted mask is `type_identifier_grid/` beside the elevation grid (bathy-global.md row 1). Finer measured cells: GMRT v4.5.0 (~100 m multibeam, `layer=topo-mask` returns only measured cells; survey footprints in `gmrt_swath_polygons.zip`; CC BY 4.0; GLOBAL rows 2-3). Polar: IBCAO v5.2 (100/200/400 m, TID and SID grids on CEDA) and IBCSO v2 (500 m, CC BY 4.0, PANGAEA) in the GLOBAL report. Regional compilations carrying many national sources: EMODnet DTM 2024 (EUROPE-W row 1; measured mask in its WFS `source_references`), GA AusBathyTopo 250 m 2026 (own TID grid, OCEANIA row 1), NOAA BlueTopo and CRM/CUDEM (NAMERICA section 2.1).

## 3. Best open source per sea, coast and lake where one beats the global grid
Built by reading the eight reports' tables. One row per qualifying product, grouped by report section (read the section column to find the water body; where several products cover the same water the finest open spacing is the best). A row qualifies when, read against its report row, all hold: it is a bathymetry grid, DEM, mesh or satellite-derived depth surface of a sea, coast, lake or river (not contours, points, a land DEM, a map picture, a pointer, or a hypsometry table); its licence cell reads open (CC BY, CC0, OGL, Licence Ouverte, public domain, KOGL Type 1, DL-DE, ODC-By; share-alike is accepted, non-commercial, no-derivatives, restricted, unclear and login-gated are not); and its spacing is 250 m or finer (GEBCO_2026 is about 460 m). Global grids themselves (GEBCO, GMRT, ETOPO) are in section 2. Cells are copied from the report rows; only the jurisdiction, product, measured/interpolated and datum cells are shortened ("[cut; see report]"); spacing and licence are whole. Coverage index is the first URL of the report's footprint cell. Datum cells show where a height, not a depth, is stored (section 4). Where the report's licence cell itself carries a caveat (a conflicting record, one restricted sub-item), the caveat is in the licence cell.

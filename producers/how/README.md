# The drop boxes' how/ notes, staged

What each drop box's `how/` folder on the NAS holds (docs/inputs.md §8), kept here so it has a
history and review. `<box>/` here is copied into `inputs/<box>/how/` on the NAS
(`timetables/feeds/` into `inputs/timetables/feeds/how/`, and so on), beside what is already there;
`inputs-README.md` is `inputs/README.md`. The input check never reads a drop box's top-level `how/`
(nor `todo/`), so copying changes no accepted version and rebuilds nothing.
